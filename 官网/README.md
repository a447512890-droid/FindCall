# 微微打电话 官网

独立纯静态官网。直接用浏览器打开 `index.html`，或将本文件夹内容放到静态服务器，无需安装依赖、构建或运行后端。

## 文件

- `index.html`：首页、功能介绍、四个场景示例、五维复盘与常见问题。
- `styles.css`：桌面和手机自适应布局。
- `script.js`：场景切换、键盘操作和页脚年份。
- `assets/app-logo.png`：用户提供的应用 Logo，用于页首、页尾及浏览器图标。

## 内容与交互

按 2026-10-22 项目当前需求编写：演练、独立实战拨打、授权录音、手动发起转写、手动选择关联演练后复盘。会员演练日额度采用当前《功能调用限制规则》的15分钟。示例界面、对话和评分均为虚构展示，不连接AI、不采集音频、不拨打电话。

页面不依赖原型目录，不加载外部字体、CDN、第三方脚本或项目配置，不含API Key。支持直接双击打开、场景点击和方向键切换、原生FAQ展开，以及减少动态效果的系统偏好。

目前未提供正式商店下载地址，因此未放置下载按钮、二维码、虚构联系方式或未完成的协议链接。后续拿到正式下载地址后，可替换页首和页尾主要入口。站点独立保存在项目根目录“官网”中，未修改原型，也未部署到线上。
